# Computational Image Features and Students' Preference Ratings in Digital Reading Assessment
This repository contains the Python code used in my Master's thesis:
Digital-Based Reading Assessment: Students' Preference Ratings and Computational Image Features

### Description
The project investigates whether computational image features—saturation, contrast, and colorfulness—are associated with students' preference ratings for reading stories in a digital reading assessment.

Python 3.11
